📥 Installation

01 — Clone Repository

git clone https://github.com/primemaruf7/Prime-maruf

02 — Open Project Directory

cd Prime-maruf

03 — Install Dependencies

npm install

04 — Configure

Open:

config.json

Configure the required bot settings according to your setup.

05 — Start Bot

npm start

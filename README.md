🚀 "07" — QUICK START

⚡ 01 — Clone Repository

git clone https://github.com/maruf-1718/MARUFS-BOT

📂 02 — Enter Directory

cd MARUFS-BOT

📦 03 — Install Dependencies

npm install

⚙️ 04 — Configure

Open:

config.json

Configure the required bot settings according to your setup.

🔥 05 — Start

npm start
